# FinSight Analytics - Loan Portfolio Risk & BI Platform

> **UST 3DSA-1 | DSA4157: Business Intelligence**  
> Proposed Domain: `finsightanalytics.com` (Spaceship)

## 📌 Project Overview
FinSight Analytics is a fintech business intelligence dashboard that integrates an analytical banking schema to deliver:
- **Interactive Portfolio Risk Monitoring**: Early delinquency (1-30 DPD), NPL tracking, and stated purpose loan distributions.
- **Predictive ML Scoring Sandbox**: Real-time loan default risk probability calculation based on borrower parameters.
- **OpenNPL Compliance Bridge**: Automated mapping to European Banking Authority (EBA) non-performing loan standards (>90 DPD).

## 🛠️ Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Recharts, Lucide React
- **API & Serving**: FastAPI (Python 3.14)
- **Database**: PostgreSQL (26-table star-compatible schema)
- **Compliance**: OpenNPL (Django 5.2 Container)
